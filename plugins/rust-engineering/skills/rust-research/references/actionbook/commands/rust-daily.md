# `rust-daily` adapter

Product route: explicit `rust-research news day|week|month`.

Use the [Rust news protocol](../rust-daily/overview.md). State the time window and timezone, prioritize official Rust and Foundation sources, use This Week in Rust as curated discovery, label Reddit as low-trust signal, deduplicate events, and cite canonical source pages. No source quota, automatic cache, or scheduled fetch is required.
